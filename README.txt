PERSONAL PORTFOLIO WEBSITE
==========================
Author  : Ch Anusha Raj
Project : HTML & CSS Internship Project - Personal Portfolio Website
Tech    : HTML5 and CSS3 only (no JavaScript, frameworks or backend)

DESCRIPTION
-----------
A responsive personal portfolio website that introduces me, shows my
education, skills and projects, and gives my contact details. It was
built with semantic HTML5 and styled with a separate CSS file.

FOLDER STRUCTURE
----------------
Anusha_HTML_CSS_Portfolio/
  index.html   - page structure and content
  style.css    - all styling and responsive rules
  images/      - folder for images (empty)
  README.txt   - this file

SECTIONS
--------
1. Header / Navigation (Home, About, Skills, Projects, Contact)
2. Home (hero) with buttons linking to Projects and Contact
3. About Me (biography, education, career interests)
4. Skills (6 skill chips)
5. Projects (6 project cards with title, description, technologies)
6. Contact (email, LinkedIn and GitHub links, demo form)
7. Footer (copyright and name)

FEATURES
--------
- Semantic tags: header, nav, main, section, article, footer
- Navigation links jump to section IDs; sticky header
- CSS variables for the colour palette
- Flexbox and CSS Grid layouts
- Hover and focus effects on links, buttons, cards and form fields
- Media query for screens up to 600px wide (mobile friendly)
- Contact form is a VISUAL DEMO ONLY and does not send any data

HOW TO RUN
----------
1. Download and unzip the folder.
2. Open index.html in Google Chrome, Microsoft Edge or any browser.
3. No installation or internet connection is needed.

NOTES
-----
- The LinkedIn and GitHub links are general placeholders and should be
  replaced with my own profile URLs.
- The profile picture is shown as an "AR" initials circle.
